## 📋 Overview

This repository contains a highly detailed, 77-page PDF document serving as a complete study roadmap for Database Management Systems. It breaks down complex topics into simple explanations, real-world examples, and exam-ready answers.

---

## ✨ Key Topics Covered (8 Main Modules)

1. **DBMS Basics:** Data vs Information, DBMS vs File System, Database Users, DBA.
2. **Database Models & Architecture:** Hierarchical, Network, Relational, 1-Tier, 2-Tier, 3-Tier, Schema vs Instance.
3. **ER Model:** Entities, Attributes (Composite, Multivalued, Derived), Cardinality, Weak Entities, ER Diagrams.
4. **Relational Model & Keys:** Super, Candidate, Primary, Foreign, Alternate, Composite keys, Integrity Constraints.
5. **SQL:** DDL, DML, DCL, TCL, Joins, Subqueries, Views, Aggregate Functions.
6. **Normalization:** Functional Dependency, 1NF, 2NF, 3NF, BCNF, Database Anomalies.
7. **Transactions & Concurrency:** ACID Properties, Transaction States, COMMIT/ROLLBACK, Locks (Shared/Exclusive), 2PL, Deadlocks.
8. **Exam Revision:** Important MCQs, Short/Long Questions, and 1-Hour Final Study Plan.
